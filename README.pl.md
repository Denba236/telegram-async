# 🚀 Telegram Async — Polski

**Nowoczesny, w pełni asynchroniczny klient Telegram Bot API dla Pythona** — zbudowany z użyciem `aiohttp` dla maksymalnej wydajności i efektywności. Idealny do tworzenia wydajnych botów.

---

## ✨ Główne cechy

- ⚡ W pełni asynchroniczny (async/await)
- 🎯 Obsługa metod Telegram Bot API
- 🤖 Zarządzane boty i intuicyjny router obsługi wiadomości
- 🪝 Wsparcie webhooków i long polling
- 🔐 Zarządzanie uprawnieniami i administratorami
- 🧩 Middleware i rozszerzalna architektura
- ✅ Pełne typowanie (type hints) i testy

---

## 📦 Instalacja

Z PyPI:

```bash
pip install telegram-async
```

Ze źródeł:

```bash
git clone https://github.com/Denba236/telegram-async.git
cd telegram-async
pip install -e .
```
