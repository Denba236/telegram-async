# 🚀 Telegram Async — Українська

**Сучасний повністю асинхронний клієнт Telegram Bot API для Python** — побудований на `aiohttp` для максимальної продуктивності та ефективності. Ідеально підходить для створення високопродуктивних ботів.

---

## ✨ Основні можливості

- ⚡ Повністю асинхронний (async/await)
- 🎯 Підтримка методів Telegram Bot API
- 🤖 Підтримка керованих ботів та зручний маршрутизатор обробників
- 🪝 Вбудована підтримка webhook і polling
- 🔐 Гнучке управління правами та адміністраторами
- 🧩 Middleware та розширювана архітектура
- ✅ Повні підказки типів і тести

---

## 📦 Встановлення

З PyPI:

```bash
pip install telegram-async
```

З джерел:

```bash
git clone https://github.com/Denba236/telegram-async.git
cd telegram-async
pip install -e .
```
