# 🚀 Telegram Async — Russian

**Современный, полностью асинхронный клиент Telegram Bot API для Python** — построен на `aiohttp` для максимальной производительности и эффективности. Идеально подходит для создания высокопроизводительных ботов.

---

## ✨ Основные возможности

- ⚡ Полностью асинхронный (async/await)
- 🎯 Поддержка Telegram Bot API (актуальные методы)
- 🤖 Управляемые боты и удобная маршрутизация обработчиков
- 🪝 Встроенная поддержка вебхуков и пуллинга
- 🔐 Детальная работа с правами и администраторами
- 🧩 Middleware и расширяемая архитектура
- ✅ Полные аннотации типов и тесты

---

## 📦 Установка

Из PyPI:

```bash
pip install telegram-async
```

Из исходников:

```bash
git clone https://github.com/Denba236/telegram-async.git
cd telegram-async
pip install -e .
```
